第2回のLoRA演習について、学習条件の変更、自作FAQ、用語集SFTと検索の比較を実施し、回答・設定・学習材料・実行結果を保存しました。

- 基礎：20→10エポックで学習時間224→113秒、内容正解率19/21→16/21。形式遵守率は両方21/21。
- 実装：架空の地理データFAQへ置換。形式0/21→21/21、内容0/21→20/21。根拠なしの質問の作り方と、過剰な確認要求の例を記載。
- 発展：58語・116件で3エポック学習し、学習前／学習後／学習前＋検索の15問を比較。自動代理指標は1/15、3/15、13/15。語句検出の誤判定や検索後の読み違いを原文とともに記録。

検証：本人がColabで各学習を実行。アップロードした結果ZIPとノートブックの表示が一致し、保存された各回答から指標を再集計して一致を確認。発展の116件は元スクリプトの生成規則と一致し、評価15問の質問文は学習質問と重複しないことを確認しました。自動指標を意味的な正解率とは扱っていません。
